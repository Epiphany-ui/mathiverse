# Design System References

When making ANY frontend/UI/design changes, consult the design reference files in `design-refs/` for inspiration. These are DESIGN.md files extracted from [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) — formal design system specifications for top products.

**Always read `design-refs/claude.md` first** — it's our primary design system (Anthropic warm cream editorial).

For specific patterns:
- **Card variety / pastel tints**: `design-refs/notion.md`, `design-refs/figma.md`
- **Bold typography / negative tracking**: `design-refs/framer.md`, `design-refs/stripe.md`
- **Dark surfaces / code mockups**: `design-refs/vercel.md`, `design-refs/supabase.md`
- **Atmospheric gradients / hero blobs**: `design-refs/framer.md`, `design-refs/stripe.md`
- **Clean minimalism**: `design-refs/linear.app.md`, `design-refs/apple.md`
- **Music / creative energy**: `design-refs/spotify.md`

Use these as reference BEFORE writing UI code. Match tokens, spacing, typography, and component patterns from the relevant reference.
